# Reflection Paper

## Reflection on Cloud Computing and Version Control

Technology has become an essential part of my daily life. I use cloud-based services such as Google Drive, Gmail, and online collaboration tools to store files, communicate, and access information from different devices. These technologies make my daily tasks easier, faster, and more convenient.

Through this course, I learned that cloud computing is more than just online storage. It includes different service models such as Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS). I also learned about deployment models including Public, Private, Hybrid, and Community Cloud, each designed for different purposes and organizations.

I also discovered the importance of Git and GitHub as version control tools. Instead of creating many copies of the same file, Git helps track every change made to a project, while GitHub allows files to be stored online and shared with others. These tools make collaboration easier and help prevent losing important work.

Overall, this activity improved my understanding of cloud computing and version control. As an IT student, I believe these skills are important because they prepare me for future software development projects and professional work environments. I will continue practicing these tools to become more organized, productive, and ready for a career in the technology industry.
